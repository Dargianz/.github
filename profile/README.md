# Dargianz

## DigitalDocTrack

DigitalDocTrack (DTS) is an institutional document tracking system for registering, routing, reviewing, signing, and archiving documents across offices.

### Projects

| Project | Description |
| --- | --- |
| [Avalonia-DTS](https://github.com/Dargianz/Avalonia-DTS) | Cross-platform Avalonia frontend for desktop, browser, Android, and iOS |
| [DDT-Backend](https://github.com/Dargianz/DDT-Backend) | ASP.NET Core backend for documents, workflows, offices, users, roles, and notifications |

### Current Direction

- API-backed document workflows
- Office-aware routing and access
- Configurable workflow stages and transitions
- Document metadata, QR references, revisions, signatures, and timelines
- Cross-platform institutional UI

### Branches

- `canary`: active development and integration
- `stable`: release baseline

### Status

DTS is under active development. Interfaces and APIs may change as workflow and office-management requirements are refined.
